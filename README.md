# Responsible Self-Defense Guide

A safety-first preparedness website for home, parking-lot, and large-public-area scenarios.

This project intentionally does not recommend firearms, calibers, confrontation tactics, or weapon selection. Its priority order is awareness, distance, escape, emergency contact, medical care, de-escalation, training, and secure storage.

## Run

```bash
npm test
npm start
```

## Included

- Scenario picker for home, parking/garage, and large public areas
- Emergency action guidance
- Practical non-weapon preparedness checklist
- CPR, first-aid, bleeding-control, and de-escalation training prompts
- Secure-storage guidance
- State-law attorney-resource links
- Civil-liability and legal-process warning
- Printable safety plan

This is not legal advice or emergency guidance. Call emergency services when there is immediate danger. Laws vary by state and facts; consult a licensed attorney.
